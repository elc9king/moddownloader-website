Privacy Policy

Last updated:

This Privacy Policy covers two distinct things: this website and the ModDownloader launcher application. They collect different (and very little) information, as described below.

A. Information collected

The website

This is a static website. It does not use cookies, analytics, trackers, embedded third-party scripts, web fonts, advertising, or forms. It does not collect or store personal information, IP addresses, or browsing behavior.

The web server that hosts this site may automatically keep basic technical access logs (such as requested URLs, timestamps, and IP addresses) — this is standard behavior of virtually all web hosting. [ADD VERIFIED INFORMATION: hosting provider and log retention, once the site is deployed.]

The launcher application

The launcher runs locally on your computer. It stores configuration, instances, settings, and account profiles in local files on your own machine. It has no telemetry or analytics of its own.

When you use its online features, the launcher makes requests to third-party services you interact with directly:

  • Mojang/Microsoft version manifest — to list available Minecraft versions.
  • Modrinth API — to search mods and download files and mod icons you view.
  • CurseForge API — only if you enter your own CurseForge API key in Settings. Your key is stored locally and sent only to CurseForge.
  • Fabric Meta — to resolve Fabric/Quilt loader versions.
  • Microsoft account sign-in — if you use Microsoft login, the standard Microsoft OAuth flow applies; Microsoft's own privacy terms govern that process. Login tokens are stored locally on your computer.

B. Why information is collected

The website collects no personal data. Any server-side access logs exist solely for operating and securing the website (e.g. diagnosing outages or abuse). The launcher's local data exists solely so the application can function on your computer.

C. How information is used

Because the website collects no personal information, none is used. Launcher data is used only locally: to launch Minecraft, download the mods you request, and remember your settings. Nothing is sold, analyzed, or profiled.

D. Data sharing

We do not sell or share personal information. The launcher itself sends no personal data to us. When you actively use its features, your requests go to the third-party services listed in section A under their own privacy policies.

E. Third-party services

  • Modrinth — mod search/downloads and images
  • CurseForge — mod search/downloads (requires your API key)
  • Fabric Meta — Fabric/Quilt loader metadata
  • Mojang — Minecraft version manifest and game files
  • Microsoft — Microsoft account sign-in (if you choose to use it)

This website itself loads no third-party scripts, fonts, videos, maps, CAPTCHAs, or analytics.

F. Data retention

Website: no personal data is retained by the website itself. [ADD VERIFIED INFORMATION: server log retention period.] Launcher: local data is kept on your computer for as long as you keep it; uninstalling the application leaves local data in your user folders, which you can delete at any time.

G. Data security

The website is served over HTTPS. Because the website collects no personal data and the launcher stores data locally, there is no central database of your information to breach. The application itself does not currently publish an independent security audit or certification, and we make no claims of one.

H. User rights

Because we hold no personal data about you, there is generally nothing for us to access, correct, or delete. If you believe we hold personal data about you in any circumstance, you may request access, correction, or deletion using the contact information below.

I. Data deletion / correction requests

Contact us at the address in the Contact section and describe your request. To remove data stored by the launcher on your own computer, delete the launcher's data folder(s) from your user directory, or uninstall the application. [ADD VERIFIED INFORMATION: exact local data paths.]

J. Children's privacy

The website and launcher are not directed at children under 13 and collect no personal information from anyone, including children. Minecraft itself is subject to Microsoft's and Mojang's own account policies, including their parental-consent requirements.

K. Changes to this Privacy Policy

If the website or launcher adds any data collection (e.g. analytics or download counting), this policy will be updated and the "Last updated" date above will change before those features go live.
