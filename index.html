FAQ

What is ModDownloader?
ModDownloader is a Windows launcher for Minecraft that lets you search and download mods from Modrinth and CurseForge, manage game instances, sign in with a Microsoft account, and launch Minecraft — with an optional in-game HUD client built in.
Which Minecraft versions are supported?
The launcher fetches available versions from Mojang's official version manifest, so all current versions are selectable in-app. Recent releases the current build targets include 1.21 through 1.21.11.
Which mod loaders are supported?
Fabric, NeoForge, Quilt, and Vanilla are supported. Forge is experimental: it is selectable, but launching may fall back to the vanilla client while Forge loader metadata is unavailable.
How do I install ModDownloader?
Download from the Download page, run the installer, and follow its steps. Full walkthrough: Installation guide.
