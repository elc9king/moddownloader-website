What's new

Initial development build. The launcher ships with the following verified functionality:

New features

  • Mod, shader, and resource pack search and download via Modrinth and CurseForge (CurseForge requires your own API key)
  • Instance management with per-instance Minecraft version, loader, and memory configuration
  • Minecraft version selection fetched from Mojang's official version manifest
  • Microsoft account sign-in and offline profiles
  • Built-in FastClient in-game HUD modules (FPS, CPS, keystrokes, coordinates, armor status, and more)
  • Server list management
  • Hardware-aware performance recommendations and video settings guidance

Improvements

  • Windows installer bundles a private Java runtime — no separate Java install required
  • Fabric and Quilt launching via Fabric Meta loader profiles; Forge/NeoForge fall back to vanilla launching when loader metadata is unavailable
