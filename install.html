Installation guide

ModDownloader is distributed for Windows as an installer (, ). The installer includes a private Java runtime, so you do not need to install Java separately.

Installing

  1. Download ModDownloader. Get from the Download page.
  2. Open the downloaded file. Double-click the installer. Windows may show a SmartScreen prompt for new software — this is standard for unsigned applications; review the file name and size before continuing.
  3. Follow the installation instructions. The installer walks you through choosing a folder (default: Program Files\Shama Client) and creating shortcuts.
  4. Launch ModDownloader. Use the desktop or Start Menu shortcut.
  5. Create or select an instance. Instances are separate game setups, each with its own version, loader, and memory settings.
  6. Select a Minecraft version and loader. Versions come from Mojang's official manifest; loaders include Fabric, NeoForge, Quilt, Forge (experimental), and Vanilla.
  7. Install mods. Open the Marketplace tab, search Modrinth or CurseForge, and download mods, shaders, or resource packs directly into the instance.
  8. Add an account and play. Sign in with a Microsoft account in the Accounts tab, or use an offline profile.

We do not recommend disabling Windows Defender, SmartScreen, or any security software — keep them enabled as usual.

Using CurseForge

Modrinth works out of the box. To enable CurseForge search, you need a CurseForge API key:

  1. Register a mod developer / console account on CurseForge's official website and request an API key.
  2. In ModDownloader, open Settings and paste your key into the CurseForge API key field.

Your key is stored locally on your computer and is sent only to CurseForge's official API. See the Privacy Policy.

Troubleshooting

  • The game doesn't launch on Forge: Forge support is experimental — the launcher may fall back to the vanilla client while Forge loader metadata is unavailable. Use Fabric or NeoForge for full loader support.
  • CurseForge search fails: check that your API key is entered correctly in Settings.
  • Download issues: make sure you're using the official Download page.
